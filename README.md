--- Bank Management System in C++

A simple console based banking application developed in C++ using Object-Oriented Programming (OOP) concepts and File Handling.

--- Features
- Create Account       : Open a new savings or current account.
- Deposit & Withdraw   : Perform real-time transactions with balance checks.
- Balance Enquiry      : View specific account details.
- Account Holder List  : View all registered accounts.
- Modify/Close Account : Edit details or delete accounts.

--- Tech Stack
- Language:C++
- Concepts: Object Oriented Programming (Classes,Encapsulation),File Streams (fstream) for binary data persistence.
